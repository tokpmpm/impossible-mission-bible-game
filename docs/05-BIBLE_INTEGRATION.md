# 聖經融入 v0.6：輕鬆、不像傳教，但真的學到內容

> 2026-11-14 使用者決定：聖經融入改輕鬆、不像傳教。否決「小組模式討論題＋禱告提示」與原本 60–90 秒的結尾（都太硬）。2026-11-15 依此實作，**未經真人試玩**。

## 定位
先讓沒有信仰背景的朋友玩得投入；聖經以「老智慧」的方式出現在遊戲裡對應的時刻，結尾只配一句經文和一行小知識。**不**考聖經、**不**禱告、**不**講道、**不**要求分享，也不把合作順不順利換算成屬靈程度。第一關「暴風雨救援」是原創虛構情境，不是聖經事件；畫面上不說它是。

## 三個時刻的「老智慧」
一句短經文當隊伍小提示，附出處；浮在畫面上 8 秒或點一下就收，不佔版面、不擋按鈕（停電頁放在最底下）。

| 時刻 | 經文（和合本） | 為什麼放這裡 |
|---|---|---|
| 開局（認識隊友時間） | 不先商議，所謀無效；謀士眾多，所謀乃成。（箴言 15:22） | 每人只有一部分情報，開口問才排得出方案 |
| 停電 | 兩個人總比一個人好……若是跌倒，這人可以扶起他的同伴。（傳道書 4:9–10） | 工程師看不到符號，要靠隊友 |
| 電來了、重新規劃 | 三股合成的繩子不容易折斷。（傳道書 4:12） | 暗示：三段線索接起來，才找得到三星 |

## 結尾（約 30 秒，全部可跳過）
1. **出發揭曉**：東村…西村…北村逐一亮起，再出星等。
2. **這局發生的事**：系統紀錄的真實事件，有名字（例「停電時，阿美 看不到符號，靠 大衛、小明 的描述修好了電」），加上背包物品出場（例「回程路上，大家分著吃了 小明 帶的零食」）。不虛構互助、不評誰最重要。
3. **一句經文配一件真的事**（林前 12 章），兩局輪替不同經節：
   - 修好電 → 12:21「眼不能對手說：『我用不著你』……」配「剛才工程師沒辦法說『我用不著你們』——沒有大家的描述，電修不好。」
   - 突破口完成 → 12:14「身子原不是一個肢體，乃是許多肢體。」
   - 二星以上 → 12:26 後半「若一個肢體得榮耀，所有的肢體就一同快樂。」（全節照錄）
   - 其他 → 12:27
4. **你知道嗎？** 一行背景小知識（依局數輪替）：
   - 保羅寫這封信給哥林多的教會。哥林多是一座有兩個港口、南來北往的商業大城，教會裡的人吵成好幾派（林前 1:11–12）。
   - 保羅寫信時不在哥林多，是聽說那裡的人在鬧紛爭，才寫信勸他們「不可分黨」（林前 1:10–11）。
   - 用「身體和肢體」比喻一群人，在當時的希臘羅馬很常見；保羅拿它來說：每個人都不一樣，也都不可少。
5. **謝謝誰？** 點一位隊友（不計票、可跳過），下面一行「隨口聊聊」的輕鬆問題（剛才哪一刻你最緊張？／下一局你想換帶什麼進背包？／剛才誰說的哪句話最有用？）。不談信仰、不談隱私。

## 不做
禱告提示、小組討論題、讀經、要求說出信仰立場或私人故事、計分或比較「誰比較屬靈」、把原創故事當聖經史實。

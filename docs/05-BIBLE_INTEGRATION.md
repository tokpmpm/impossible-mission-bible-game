# 聖經與破冰收尾 v0.5（提案）

## 定位
先讓沒有信仰背景的朋友也能玩得投入，結束再自然認識聖經中的神；**不是**考聖經知識，也不把是否合作順利換算為屬靈程度。第一關「暴風雨救援」是原創虛構情境，不是聖經真實事件。

## 對應經文
哥林多前書 12:12–27：身體雖有不同肢體，卻互相需要；不能說「我用不著你」，應彼此關顧。用不同角色的資訊互補、危機時求助來體會「需要彼此」，但**遊戲不能等同或完整解釋這段經文**，也不能讓玩家覺得「能力弱就比較不屬靈」。

## 結尾 60–90 秒（可跳過，主持人可口頭帶領）
1. **結果 15 秒**：呈現一／二／三星、救援到哪些村。未送達的村在故事中由另一支救援隊接手，不宣稱其他真實房間已完成。
2. **真實事件配經節 15–20 秒**：依系統紀錄挑一至兩件客觀發生的事，直接配上對應經節位置，例如「21 節 ← 停電時，工程師靠 4 位隊友的描述修好了電力」「14 節 ← 這局的突破口從觀測員開始，經過通訊員與工程師才完成」。只陳述系統記錄到的事，不虛構人際互助，也不推測誰最有價值。
3. **認識彼此 20–30 秒**：可以點選感謝一位剛剛幫到自己的隊友（畫面只顯示誰謝了誰，不計票、不排名，可跳過），也可以自願說一句「剛剛我發現___原來很擅長___」。不想開口的人用點的就好。
4. **聖經 20–30 秒**：主持人或螢幕說明：「保羅說，身體有許多肢體，卻是一個身體；彼此不同卻互相需要。剛才哪一刻你最需要別人的幫忙？」提供哥林多前書 12:21–27 章節位置，願意深入的人可讀全文。
5. **下一局**：立即可換角色／換情境，不強迫全部發言完才能繼續。

## 經文重點與玩家實際經歷的對應（v0.5）
經節以位置與非逐字摘要表示；對應只是體驗上的呼應，不是經文的完整解釋。

| 經文重點（摘要） | 玩家在遊戲裡經歷到的事 |
|---|---|
| 身體有許多肢體（14 節） | 突破口要三個不同職能的線索接起來才成立 |
| 不能說「我用不著你」（21 節） | 停電時工程師看不到符號，只能靠隊友描述 |
| 各肢體彼此相顧（25 節） | 偏好能力與排除線索是用來幫別人的，自己用不到 |
| 你們各自作肢體（27 節） | 每局由不同職能開啟突破口，沒有固定的主角 |

## 取消或下修 v0.3 設計
- **移除**「猜這局誰是關鍵角色」匿名投票。v0.5 改用不需投票的做法：突破口每局由不同職能接力（seed 001 從觀測員開始、seed 002 從醫護員開始），結尾只說「這局的突破口從○○開始」。
- **不必**為每位玩家硬頒專屬稱號、塞滿拼圖和經節配對：8 分鐘裡更重要的是說一句真的認識別人的發現。
- 「身體拼圖」保留為**可選視覺動效**，不把觀測員＝眼睛等對應說成經文的唯一詮釋。
- 不要求公開私人故事、創傷或宗教立場；感謝卡不展示任何票數。

## 往後聖經關卡
可以研究尼希米記修城牆中分工與守望；若設計五餅二魚，不要把耶穌的神蹟錯誤簡化成玩家「只要分享資源就會自動倍增」。每關均由懂聖經內容的人審核上下文、譯本和引述授權。

## 測試
觀察未信主玩家能否理解連結而不感壓力；結尾是否真的在 60–90 秒內完成；是否至少有人說出新認識的朋友特質。若反思拖長或讓人尷尬，先簡化，不增加更多宗教表單。

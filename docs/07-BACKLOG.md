# MVP 待辦 v0.4：優先好玩、真的破冰（尚未實作）

## P0｜先完成可供 3–10 人測玩的第一關
- [ ] US-01 建立房間／QR 加入／暱稱／準備；**入房不計入 8 分鐘遊戲時長**。
- [ ] US-02 3、4、5、6、7、8、9、10 人都有明確分工與角色—線索—操作分配表；7–10 人拆分既有職能，不增加第二個難題。
- [ ] US-03 導航／補給／通訊／工程／醫護／觀測與拆分角色可見各自不同資訊；可以自由分享手機。
- [ ] US-04 共享路線、物資、危機狀態與服務端計時；手機瀏覽器即時同步。
- [ ] US-05 **seed 001**：三村急迫需求、重量、路線、安全窗、不同方案與一／二／三星（見 02 文件）。
- [ ] US-06 起始選紅線觸發紅線受阻；選藍線觸發藍線受阻；至少保留一條常規二星解。
- [ ] US-07 停電時僅有 **45 秒描述符號修復**；三名隊友提供符號（3 人場可兼任）、工程師操作；逾時協助提示，不疊加喊話混亂期。
- [ ] US-08 三段線索整合、啟動上游分洪閘門，讓綠線達成三星；確認 6 kg 與故事安全窗。
- [ ] US-09 可選答的破冰偏好題與保底線索；不能因跳過而無法通關。
- [ ] US-10 結尾真實協作回顧、60–90 秒聖經連結與下一局；不投票比較角色價值。
- [ ] US-11 伺服器一致性、重複提交防護、房主掉線與玩家重連。
- [ ] US-12 自動測試 F01–F20；至少完成 3、6、10 人真人測玩並紀錄。

## P1｜驗證好玩後擴充
- [ ] 再製作 2 個**人工設計、可驗證**的任務變體；不同情境與危機分支，但仍保留三次高潮、無額外道具。
- [ ] 加強偏好題與真人找人任務，測試最能讓陌生人交流的題目；避免強制揭露。
- [ ] 微調音效、震動、角色提示、無障礙與低動態。
- [ ] 若 7–10 人任務等待過長，按分拆職能方式增設有效線索，而非再加按確認步驟。
- [ ] 若收尾太趕，簡化動畫與稱號，保留一個真實回顧與一個聖經問題。

## P2｜避免提前堆功能
- [ ] 完整隨機題庫＋自動求解器（**人工變體試玩通過後**再做）。
- [ ] 同時間跨面板指令、受困黑屏角色、過載倒數、同步長按等危機模組：**實測顯示需要額外刺激時**才逐一 A/B 測。
- [ ] 20 人以上多房／跨隊合作與主舞台大螢幕。
- [ ] 新聖經主題（例尼希米守望），每一個先有好玩的核心互動再談擴充。

## 不做
額外實體卡片、禁止講話或互看手機、羞辱性票選、強迫發言、讓手機監督現實行為、信仰排行、每日登入與無限刷分。

## 完成定義
不是只寫完 Markdown 或 UI；必須真正可讓 3–10 人同場手機連線完成 seed 001、危機修復與分星結算，並在實測記錄「每人有效貢獻、至少交流 2 位隊友的目標、每局 5–10 分鐘」後才可說 MVP 可玩。

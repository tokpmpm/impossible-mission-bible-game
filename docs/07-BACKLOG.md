# MVP 開發待辦與驗收條件（v0.3）

> v0.3 依 `docs/02-MISSION_01_STORM_RESCUE.md` 調整優先順序：先修好核心玩法（取捨、分工、隨機化），再加破冰與結尾。

## P0｜做出第一個真正能玩、而且值得再玩的多人關卡
- [ ] **US-01 建立與加入房間**：主持人生成 QR Code，3–10 人免帳號以暱稱加入；可選答 2 個偏好題（可跳過）。
- [ ] **US-02 角色分配**：每位玩家有重要線索或功能；3–5 人可兼任，7–10 人不得當純旁觀者；連續局角色與上一局不同。
- [ ] **US-03 多角色任務面板**：導航、補給、通訊、工程、醫護、觀測各有不同資訊；可自由展示手機。
- [ ] **US-04 共享狀態**：路線、物資、重量及危機即時同步；伺服器是唯一真實狀態。
- [ ] **US-05 三村取捨與分星結局**：三村需求、6 kg 載重、★1–3 計分；未送到的村顯示由另一隊接手。
- [ ] **US-06 危機事件**：吊橋坍塌與停電只觸發一次；在「鎖定計畫」後 10–30 秒或最晚 3:30 觸發；遮住主要情報但不斷線。
- [ ] **US-07 描述型修復**：非工程師玩家按住才顯示符號；工程師從 9 個相似符號依序選出；選錯洪水提前 15 秒；成功全員恢復。
- [ ] **US-08 隱藏突破口**：seed 001「延後洪水」三段線索；驗證器確認不用突破口最高 ★★。
- [ ] **US-09 隨機化＋解題驗證器**：每局隨機參數、危機類型、突破口題庫；開局前窮舉驗證，不通過重抽。（原 P2，提前）
- [ ] **US-10 最終救援驗證**：後端驗證路線、工具、重量、時間（含延後／提前）、電力；分類錯誤提示一致。
- [ ] **US-11 房間重連**：短暫離線可恢復角色與進度。
- [ ] **US-12 倒數與超時**：伺服器計時、超時收尾與重新遊玩。

## P1｜互動與聖經體驗
- [ ] **喊話混亂期 B**：跨面板限時指令；未完成洪水提前 10 秒。（需實測與 US-07 同時進行是否過載）
- [ ] **受困角色**：危機時隨機一位非工程師面板全黑、操作保留。
- [ ] **過載與求救**：待辦 ≥2 時倒數加速；求救廣播指令給全隊。
- [ ] **破冰偏好線索**：系統挑「有人選、但不是每人都選」的偏好題產生指向人的線索。
- [ ] **猜關鍵角色**：開局匿名猜「這局誰會是關鍵角色」，最少人猜到的角色接手突破口線索；結尾以「最出乎意料的關鍵角色」揭曉，不顯示票數。
- [ ] **結尾流程**：自動回顧、感謝卡、專屬稱號、身體拼圖＋經節配對、選一題分享（見 `05-BIBLE_INTEGRATION.md`）。
- [ ] **30 秒教學小關**。
- [ ] **大螢幕投影模式**：倒數、地圖、危機動畫、可關閉音效。
- [ ] 手機 320px 寬畫面、觸控尺寸、對比與字幕檢查；低動態模式。
- [ ] 3、6、10 人現場試玩，記錄每人是否開口、完成時間、星等分布、是否主動再玩。

## P2｜擴充
- [ ] 「一起推車」觀測員喊時機的同步長按（可選機制）。
- [ ] 7–10 人「救援車隊／指揮中心」雙小隊模式。
- [ ] 20 人以上多房間活動＋全場共同危機＋跨隊接手村莊。
- [ ] 三關串成約 30 分鐘的小戰役，每關對應一段經文（先選經文再推機制）。
- [ ] 新原創關卡（如五餅二魚、尼希米修城牆），經人工內容審核。

## 暫不做
原生 App、付費商城、排行榜、每日打卡、AI 自動寫未經審核經文、大量先做沒有實測的關卡。

## 定義完成（DoD）
完成不等於「程式碼已寫」，必須能讓 3–10 人真實加入同一房間，完成一次救援、同步事件、修復、分星結算與下一局（新隨機參數），附可重現測試結果。若 UI 好看但多人不能玩，仍屬未完成。

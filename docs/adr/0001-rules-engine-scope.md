# 第一關規則引擎不認識玩家與職能

Status: accepted（2026-11-13，grill-with-docs 第 1 題）

第一輪只做 seed 001／002 的世界規則：路線、工具、載重、危機、停電與修復的**規則**、突破口、出發與分星，以及規劃期輔助（可送達村數、2:15 方向提示的觸發條件）。引擎只吃「這局幾個人」「是不是首局」這類數字，不知道誰是哪個職能、誰拿到哪個符號、提示顯示在誰的手機。

為什麼：突破口必須等恢復供電，修復規則和突破口分不開，所以修復規則要放進來；但「誰拿到什麼」取決於 3–10 人的職能分配表（F02／F03），那張表還沒做，硬塞進來會讓引擎跟著角色設計一起反覆改。

## Consequences
- 06 測試計畫中這一輪由自動測試涵蓋：F04–F06、F09–F15、F21–F25 全部；F07、F08、F26、F27、F28 只涵蓋引擎層（例：5 人局有 4 個符號＋1 個排除線索名額、逾時進入協助模式、排除能力只能用一次、2:15 觸發條件、首局多 15 秒）。分派給誰、畫面文案、斷線轉移留給房間層，測試標「待房間層」。
- 操作權限（只有指定職能能按）由房間層檢查，引擎不檢查。

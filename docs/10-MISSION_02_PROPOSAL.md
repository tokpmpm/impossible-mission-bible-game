## 0. 一頁看懂

- **故事**：尼希米帶耶路撒冷的百姓重修被燒毀的城牆。各家族「對著自己的房屋修造」；做到一半，敵人揚言偷襲，只好派人守望、人手不夠；後來尼希米安排「吹角的人」，大家聽見角聲就聚集，守望的人就不必每個缺口都站人。
- **玩法**：全隊是尼希米身邊的幫手，要把 6 支家族工隊分派到 5 段破口。每人手機只有一部分情報（破口要多少人手、每家幾個人、誰住哪一段）。危機時要派人守望、人手不夠；突破口是「號角」：把吹角的人安排在對的位置，就只需要一支守望隊，城牆能全部修好。
- **為什麼選它**：沒有要玩家「操作神蹟」；故事本身就是分工、守望、溝通。玩完的人自然知道：城牆五十二天修完、各家修自己家門前、做工的人一手做工一手拿兵器、聽見角聲就聚集。
- **和第一關差在哪**：第一關是「一台車裝什麼、走哪條路」（背包題）；第二關是「把人分到哪裡」（分派題），突破口是「溝通方式」而不是換路或換物資。
- **聖經部分**：遊戲中只出現短短的經文旁白（標出處）；結尾一句經文＋一則「你知道嗎？」，不講道、不禱告、不要求分享。

## 1. 候選故事比較

評分 1–5（5 最好）；「改編風險」分數越高代表**風險越低**。

| 面向 | A. 尼希米修城牆（尼 2–6） | B. 挪亞方舟（創 6–9） | C. 建造會幕、百姓甘心獻上（出 35–36） |
|---|---|---|---|
| 好玩程度 | **5**：有明確的分派題、中途危機（敵人揚言偷襲）、有轉折的突破口（號角） | 3：裝動物、算空間有趣，但故事中段只是等待洪水退去 | 3：收集材料、分配工匠；高潮是「材料太多要叫停」，有趣但張力低 |
| 合作／溝通機會 | **5**：經文本身就在講分工（尼 3 一段接一段）、守望（尼 4:13、16）、用角聲溝通（尼 4:19–20） | 3：一家八口照神的吩咐做，經文中幾乎沒有「大家討論決定」 | 4：比撒列、亞何利亞伯與眾工匠分工（出 35:30–36:1） |
| 能學到的聖經內容 | **5**：52 天完工、各家修自家門前、一手做工一手拿兵器、角聲聚集、祭司和銀匠、做香的、沙龍的女兒們都來修牆 | 4：大家多半已知道；能補充「潔淨的畜類帶七公七母」（創 7:2） | 4：較少人知道；「材料多到要宣告別再拿來」（出 36:5–7）很有記憶點 |
| 對非信徒友善 | **5**：本質是一個社區重建工程的故事，不需要信仰背景就看得懂 | 3：洪水是審判、全地生物滅絕，放在破冰遊戲裡情緒偏重 | 4：會幕、聖所、禮物等詞彙需要解釋 |
| 改編風險（分高＝風險低） | **4**：沒有神蹟要模擬；要注意不把敵人寫成特定民族、不渲染武器（見第 7 節） | 2：方舟尺寸與要帶什麼都是神具體吩咐（創 6:14–22），讓玩家「自己決定」就違背經文 | 4：獻禮是「甘心樂意」（出 35:21），做成資源競賽容易變味 |
| 合計 | **24** | 15 | 19 |

**選定：A. 尼希米修城牆。**

理由：
1. **故事本身就是本遊戲的核心循環**：先分工（尼 3），危機打斷（尼 4:7–12），重新分工（尼 4:13–16），用溝通找回效率（尼 4:18–20）。不必加油添醋，故事和機制天然對齊。
2. **沒有把神蹟簡化成玩家操作的風險**。城牆是百姓動手修的；經文把「敵人沒有來」歸因於神破壞他們的計謀（尼 4:15），所以遊戲**完全不模擬攻擊、也不讓玩家「打退敵人」**，星等只看城牆修了多少。
3. **第 05 號文件「往後聖經關卡」已點名尼希米**，延續既有方向。
4. 「沙龍和他的女兒們」（尼 3:12）、「做香的」（尼 3:8）、「糞廠門」（尼 3:14）這些細節本身就好笑、好記，適合作「你知道嗎？」。

替代方案：若使用者想要更多人熟悉的故事，C（會幕）可做第三關，主題是「每個人的手藝不同」；B（挪亞方舟）不建議做成合作決策關卡。

## 2. 關卡設計：五十二天的城牆

### 2.1 一句話玩法
大家是尼希米的幫手。先交換情報，把 6 支家族工隊分到 5 段破口；天黑時敵人揚言偷襲，全隊一起對好「角聲暗號」；天亮後要派人守望、人手不夠，得決定哪一段先放著。找到「吹角的人該站在哪裡」，就能少派一支守望隊，讓整圈城牆連起來。

### 2.2 沿用與不沿用第一關的骨架

| 沿用（已確定的骨架） | 第二關特有的機制 |
|---|---|
| 三次高潮：規劃 → 單一危機＋描述型合作 → 重新決策＋突破口 | 規劃是**分派題**（人→地點），不是裝載題（物品→車） |
| 危機最晚 2:45 觸發；遮罩期間只做一件事 | 遮罩是**夜色**，合作任務是**對角聲暗號**（可以拍手、哼出來） |
| 危機前不顯示「能完成幾段」，揭曉在遮罩畫面（比照 2026-11-14 決策） | 危機的代價是**人手被抽走去守望**，不是封路也不是載重下降 |
| 突破口三段線索、輪替起點職能 | 突破口是一個**位置推理**：角聲只傳得到相鄰的城牆段 |
| 二星＝任務成功；拒絕開工不算失敗 | 「急迫」的是**兩處低窪空處**（尼 4:13），不是兩個村 |
| 故事時間與房間倒數分開 | 本關沒有故事時鐘；只有「人手」單位，更好算 |

### 2.3 世界規則（seed 201）

**城牆**：五段破口圍成一圈，順序照尼希米記第 3 章的城門次序（羊門 → 魚門 → 谷門 → 糞廠門 → 泉門 → 回到羊門）。泉門與羊門相鄰。

| 破口 | 需要人手 |
|---|---|
| 羊門段 | 4 |
| 魚門段 | 3 |
| 谷門段 | 4 |
| 糞廠門段 | 2 |
| 泉門段 | 3 |

**家族工隊**（人手數是遊戲設定，經文沒有記載各家人數）：

| 工隊 | 人手 | 自家段（尼 3 記載他們修的地方） |
|---|---|---|
| 祭司們（以利亞實和眾祭司，尼 3:1） | 3 | 羊門 |
| 哈西拿的子孫（尼 3:3） | 2 | 魚門 |
| 撒挪亞的居民（尼 3:13） | 3 | 谷門 |
| 瑪基雅家（尼 3:14） | 1 | 糞廠門 |
| 沙崙家（尼 3:15） | 2 | 泉門 |
| 沙龍和他的女兒們（尼 3:12） | 2 | 無（他們修的那段不在這五段裡，可以支援任何一段） |

**自家段加成**：工隊在自家段修造時人手 +1。這是**遊戲化的規則**，靈感來自經文中「各對自己的房屋修造」（尼 3:23、28）；經文沒有說這樣比較快，結尾不會這樣宣稱。

**完工**：一段破口上所有工隊的人手（含加成）≥ 需要人手即完工。一支工隊只能去一個地方，不能拆開。

**星等**
- ★★★：五段全部完工（「城牆就都連絡」，尼 4:6）。
- ★★：兩處低窪空處（谷門段、泉門段）都完工 → 標題「任務成功」。
- ★：至少一段完工，但沒有補好兩處低窪空處。
- **拒絕收工、可修改再送**：還在夜裡（暗號未對好）／守望隊不夠／沒有任何一段完工。不給星、不算失敗、不限次數。

### 2.4 危機前（0:00–2:45）

- 全部工隊都在自家段：羊 4、魚 3、谷 4、糞 2、泉 3，**剛好五段全部完工**；沙龍和女兒們去哪一段都可以。→ 危機前有三星方案。
- 隨便分會失敗。例：祭司們去魚門、哈西拿的子孫去羊門 → 羊門只有 2、不夠 4。要發現「自家段 +1」這條規則，才會想到「讓每一家修自己家門前」。
- 危機前的三星方案共 15 種（窮舉），全部 15,625 種分法中約 0.1%。不是靠亂點會碰到的。

**2:15 方向提示**（只在尚未觸發危機時出現一次，給工頭）：「名單上寫，很多人是『對著自己的房屋修造』。」只指方向，不給答案。

**中段輕鬆事件**（1:30，只是一行字幕，不影響規則）：「多比雅在旁邊冷笑：『他們所修造的石牆，就是狐狸上去也必跐倒。』（尼 4:3）」

### 2.5 危機（固定）：敵人揚言夜襲＋夜色遮罩（2:45 前鎖定或時間到）

觸發後畫面文案（不怪玩家，帶一點幽默）：
> 「消息傳來：有人同謀要趁夜來擾亂（尼 4:8、11）。天黑了，先把集合的角聲暗號對好！狐狸暫時沒來。」

**夜色遮罩（45–60 秒，唯一任務）：對角聲暗號**
- 吹角者面前有 2–4 格，每格從 9 個相似的角聲圖樣中選一個。
- 每個圖樣由三個可以說、也可以「表演」的特徵組成：
  - **聲數**：3、4 或 5 聲
  - **長聲位置**：第一聲長／中間長／最後一聲長
  - **結尾**：往上揚／往下沉
- 持有暗號的隊友長按看到自己的圖樣（例：「嘟——嘟嘟嘟↑」，下方附文字「四聲，第一聲長，結尾往上」）。可以用說的、拍手、哼出來、或直接把手機給吹角者看——都可以。
- 其他非吹角者每人一條**排除線索**（例：「暗號裡沒有五聲的」）。
- 人數對應同第一關：3 人 2 格、4 人 3 格、5–10 人 4 格；逾時進入協助模式（灰掉一半錯誤選項，再 15 秒剩 2 選 1）；首局多 15 秒。
- 遮罩畫面同時揭曉：「原本的分派能完工 ○／5 段」。

設計理由：拍手和哼節奏會讓人笑、會讓人靠近彼此，比描述圖形更有現場感；而且「角聲」在這裡先出現一次，後面的突破口就有伏筆，玩家回想起來會覺得「原來號角不只是暗號」。

### 2.6 危機後（天亮，約 3:45–6:30）

規則變化：
- 敵人會從**谷門段與泉門段後面的低窪空處**來（尼 4:13 只說「城牆後邊低窪的空處」，指定哪兩段是遊戲設定）。
- 需要派 **2 支工隊守望**。守望的工隊不能修造（經文「一半做工，一半拿槍」，尼 4:16）。
- 原本的分派全部保留，畫面直接提示「還需要派 2 支守望隊」。危機後即時顯示「能完工 ○／5 段」。

| 方案（未啟動號角） | 結果 |
|---|---|
| 原方案、不派守望 | 拒絕收工：守望隊不夠 |
| 瑪基雅家＋沙龍父女守望，其餘在自家段 | ★★（糞廠門段沒人修） |
| 哈西拿的子孫＋沙龍父女守望，其餘在自家段 | ★★（魚門段沒人修） |
| 沙崙家＋瑪基雅家守望，沙龍父女去泉門 | ★（泉門只有 2，不夠 3） |
| 撒挪亞居民＋瑪基雅家守望，沙龍父女去谷門 | ★（谷門只有 2，不夠 4） |

六支工隊扣掉兩支守望只剩四支，不可能補滿五段：**沒有突破口時最多二星**。要決定的是「哪兩支去守望、哪一段先放著」，而且守望的人選會影響低窪空處能不能補好。

### 2.7 三星突破口：吹角的人

**三段線索（seed 201 從文士開始）**
1. **文士**（記錄尼希米說的話）：「工程浩大，大家在城牆上相離甚遠；只要聽見角聲在哪裡，就聚集過去。若有人吹角，守望只要一支隊伍。」（改寫自尼 4:19–20）
2. **吹角者**：天亮後面板出現「安排吹角的人」，要選一段城牆當位置。
3. **夜巡員**：「我夜裡試過：角聲只聽得到自己這一段和左右相鄰的兩段。」

**推理**：兩處低窪空處是谷門與泉門；在環上，只有夾在中間的**糞廠門**同時與兩處相鄰 → 吹角的人要站在糞廠門段。

**效果**：吹角位置正確 → 守望隊需求由 2 降為 1。位置錯誤 → 友善回覆（例：「從谷門吹，泉門那邊聽不到」），可以重試，不扣分。

| 方案（號角在糞廠門） | 結果 |
|---|---|
| 沙龍父女守望，其餘五家在自家段 | ★★★ |
| 瑪基雅家守望，沙龍父女去糞廠門 | ★★★ |
| 哈西拿的子孫守望，沙龍父女去魚門 | ★★（魚門 2，不夠 3） |
| 號角放在谷門，只派沙龍父女守望 | 拒絕收工：號角聽不到泉門，仍要 2 支守望 |

**經文對照的分寸**：經文中角聲是為了讓分散的人能聚集（尼 4:19–20），同時仍有一半的人拿兵器（尼 4:21）。遊戲只取「有角聲就不必每個缺口都站人」這一點，守望隊仍然存在，不會變成「有號角就不用守望」。

### 2.11 畫面重點

1. **主畫面是一圈俯視的城牆**：五段破口像五塊缺角的拼圖，城門小圖示（羊、魚、山谷、垃圾桶造型的糞廠門、水滴的泉門）讓不識字或不熟名字的人也能指認。
2. **工隊是可拖曳的人物卡**：卡上用簡單人形數表示人手（●●●），有自家段的工隊在卡角顯示小屋圖示——**但「是哪一段」只出現在文士手機上**，其他人要問。
3. **完工進度只在危機後顯示**：每段一條進度條；危機前只顯示「已分派」，不顯示是否夠（依 2026-11-14 決策）。
4. **夜色**：畫面暗藍、只剩一圈火把光照著角聲格子；圖樣用長短橫條＋箭頭表示，下面有文字描述。
5. **天亮後**：兩處低窪空處閃黃色、出現「守望」欄位；號角安排好後，畫面從號角畫出一圈聲波，蓋到相鄰兩段，視覺上一看就懂「為什麼放這裡」。
6. **不畫戰鬥、不畫敵人臉孔**：守望隊用舉火把、站崗的剪影表示；敵人只以「遠方的火光與傳言」出現。

## 3. 聖經內容怎麼「學到」又不像上課

### 3.1 原則
- **故事照經文走**：重建緣由（尼 1–2）→ 夜間察看（尼 2:12–15）→ 各家分段修造（尼 3）→ 被嘲笑（尼 4:1–3）→ 揚言偷襲、派人守望（尼 4:7–16）→ 角聲（尼 4:18–20）→ 五十二天完工（尼 6:15）。
- **遊戲中只出現短旁白**，每句都標出處；**引號內一律逐字**，改寫的句子明確寫「改寫自」，不加引號。
- **人手數、哪兩段低窪、自家段加成、守望隊數量都是遊戲設定**，結尾不把它們說成史實。
- **不模擬攻擊、不讓玩家「贏過敵人」**。結算畫面寫「這一夜敵人沒有來」，對應尼 4:15，不說是玩家的功勞。
- **結尾只有一句經文＋一則「你知道嗎？」**，30 秒內讀完；沒有講道、禱告、填表或必須分享。主持人想多帶，可以自行延伸，遊戲本身不要求。

### 3.2 遊戲事件與經文細節的對應

| 遊戲中發生的事 | 經文 | 玩家記得的點 |
|---|---|---|
| 開場：城牆破、城門燒了 | 尼 2:13 | 城牆為什麼要修 |
| 夜巡員知道每段破口狀況 | 尼 2:12–15（夜間察看；牲口沒有地方過去） | 尼希米先摸清狀況再動員 |

### 3.3 結尾 60–90 秒（沿用第一關流程，內容換成本關）
1. **結果 15 秒**：星等＋城牆完成幾段。未完工的段落「隔天繼續修」，不說失敗。
2. **真實事件 15 秒**：系統挑一件客觀記錄，例如「這局的突破口從文士開始，經過吹角者和夜巡員」「夜裡吹角者靠 4 位隊友的節奏對好了暗號」。
3. **一句經文**（固定，畫面顯示 10 秒）：
   > 「這樣，我們修造城牆，城牆就都連絡，高至一半，因為百姓專心做工。」（尼希米記 4:6）
4. **你知道嗎？**（從下表依本局事件挑一則，一則就好）。
5. **認識彼此**：可點選感謝一位隊友（不計票）、可自願說一句新發現；不想說可跳過。
6. **下一局**。

**為什麼選尼 4:6 當固定經文**：它直接描述玩家剛做的事（各自專心做工、城牆連起來），不需要解釋；三星的「城牆連絡」就出自這句，玩家看到會有「原來如此」的感覺。替代方案：尼 2:18「我們起來建造吧！」（更有號召感，但與結果較無關）；尼 6:16（講完工出於神，信仰意涵較直接，適合教會小組場合，可做為主持人模式的選項）。

- **不推翻 DECISIONS.md「已由使用者確定」任何一條**：3–10 人、只用手機、可互看可說話、遮罩只是遊戲畫面、好玩優先再自然連結聖經。

## 6. 數值如何窮舉驗證

做法同 `tools/verify_seeds.py`：把每支工隊可以去的地方（5 段之一，危機後再加「守望」）全部列舉，6 支工隊 → 危機前 5⁶＝15,625 種、危機後 6⁶＝46,656 種，每種算星等。再加上號角的 5 個位置。

**要通過的規則**（兩個種子都要）
1. 危機前可三星。
2. 危機後、沒有號角：最高二星，且二星解存在。
3. 只有一個吹角位置能同時聽到兩處低窪空處。
4. 號角在正確位置：可三星。
5. 號角在錯誤位置：最高二星。
6.（seed 202 額外）沙龍父女當唯一守望時無法三星，迫使第二局重算。

**試算結果（2026-11-14，暫存腳本；不是遊戲測試）**

| 規則 | seed 201 | seed 202 |
|---|---|---|
| 危機前最佳／三星解數 | ★★★／15 | ★★★／11 |
| 危機後無號角最佳 | ★★ | ★★ |
| 唯一正確吹角位置 | 糞廠門 | 魚門 |
| 號角正確：最佳／三星解數 | ★★★／2 | ★★★／1 |
| 號角錯位：最佳 | ★★（四個錯誤位置皆是） | ★★（四個錯誤位置皆是） |
| 號角後三星時的守望人選 | 沙龍父女 或 瑪基雅家 | 只有瑪基雅家 |

```python
        need_g = 0
    elif phase == "horn" and horn_ok(seed, horn_pos):
        need_g = seed["horn_guards"]
    else:
        need_g = seed["guards"]
    g = sum(1 for a in assign.values() if a == "守望")
    if phase == "pre" and g: return 0, "危機前不需守望"
    if g < need_g: return 0, f"守望不足（需 {need_g} 支）"
    p = {s: 0 for s in SEGS}
    for t, a in assign.items():
        if a == "守望": continue
        size, home = seed["teams"][t]
        p[a] += size + (1 if home == a else 0)
    done = [s for s in SEGS if p[s] >= seed["needs"][s]]
    if not done: return 0, "沒有任何一段完工"
    if len(done) == 5: return 3, "城牆連絡"
    if all(l in done for l in seed["low"]): return 2, "兩處低窪空處都補好"
    return 1, "未補好兩處低窪空處"
def best(seed, phase, horn_pos=None):
    names = list(seed["teams"])
    opts = SEGS + ([] if phase == "pre" else ["守望"])
    top, n3 = 0, 0
    for combo in itertools.product(opts, repeat=len(names)):
        s, _ = stars(seed, dict(zip(names, combo)), phase, horn_pos)
        n3 += s == 3
        top = max(top, s)
    return top, n3
```

**暫定拒絕原因順序**（比照 ADR 0003 第 5 條）：還在夜裡 → 守望隊不夠 → 沒有任何一段完工。

| 風險 | 對策 |

## 8. 待試玩驗證（全部未測試）
- 1 分 45 秒內能否拼出「自家段 +1」並排出三星；找不到的隊伍是否仍覺得有趣。
- 夜色對暗號：拍手／哼節奏是否真的讓人笑、讓人靠近；45／60 秒是否夠。
- 危機後「派誰守望」是否引發真正的討論，而不是工頭一人決定。
- 號角推理（相鄰段）是否太明顯或太隱晦；聲波視覺是否讓人一看就懂。
- seed 202 第二局是否需要重新思考；唯一三星解是否太難。
- 3／6／10 人每人是否都有有效貢獻；第 7–10 人的拆分職能是否真的影響決策。
- 結尾一句經文＋一則小知識是否在 30 秒內讀完；非信徒是否覺得「學到東西」而不是「被傳教」。
- 名字與城門名對新朋友的負擔。
